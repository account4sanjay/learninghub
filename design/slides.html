LEARNINGHUB /Presentation

LearningHub
one portal for a school.

Students, teachers and administrators of a high school share schedules, classes, term lesson plans, timed assessments, submissions and grading, and term tuition — built as seven Spring Boot microservices with Keycloak and Postgres behind one gateway, and a Svelte front end.

LEARNINGHUB /The theme
What it does

Three roles, one portal

01 / Student

Learn and keep up

Weekly / term / calendar schedule of enrolled classes; browse and enrol. Term lesson plan per subject. Timed quizzes and tests with autosave and auto-submit; assignments with file upload. Results, feedback, term tuition and receipts.

02 / Teacher

Teach and assess

Classes taught and rosters by grade level. Mark each class of the lesson plan complete — students see it at once. Author assessments with questions, review every submission, grade assignments.

03 / Admin

Run the school

Users and roles (Keycloak), subjects with quarter terms, days and one-hour slots, enrollment by subject, payments for the whole school, a school-wide dashboard.

Svelte 5 SPASpring Cloud Gateway + Eureka7 Spring Boot 3.5 / Java 21 servicesKeycloak 26 · 3 roles6 Postgres databases · Flyway64 REST operations · Swagger

LEARNINGHUB /Architecture
Components and services

One origin, seven services, one database each

The gateway routes /api/** by path to the services (found in Eureka), /auth/** to Keycloak and everything else to the SPA. Every service validates the caller's JWT and shapes its views by role.
